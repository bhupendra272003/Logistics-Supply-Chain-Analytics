Logistics & Supply Chain Performance Dashboard

Project Overview

An interactive logistics analytics project built to monitor shipment performance, transportation modes, carrier activity, freight costs, and delivery delays.

Tools Used

- SQL: Data querying and validation
- Python: Data cleaning using "clean_data.py"
- Power BI: Interactive dashboard, KPI cards, charts, and slicers

Dashboard Features

- Total shipments
- Average transit days
- Total freight cost
- Total delay days
- Shipment distribution by shipping mode
- Monthly shipment trends
- Shipment count by carrier
- Interactive filters for shipping mode and region

Repository Contents

- "clean_data.py" — Python data-cleaning script
- "carriers.csv" — Carrier reference data
- "locations.csv" — Location reference data
- "orders_raw.csv" — Raw orders data
- "shipments_raw.csv" — Raw shipments data
- "dashboard output.png" — Dashboard screenshot

Key Learning Outcomes

- Working with logistics datasets
- Preparing data for analysis
- Building interactive Power BI visuals
- Comparing carrier and shipping-mode performance
- Presenting operational KPIs in a dashboard

Notes

This project is intended for learning and portfolio demonstration. Findings should be validated against the underlying data before being used for operational decisions.
